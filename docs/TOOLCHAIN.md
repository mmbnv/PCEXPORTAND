# Toolchain

PortAgent's analysis and verification run with **no external tools** (stdlib
Python + a host C compiler). The full porting pipeline additionally uses the
tools below. Install the Android-side toolchain with:

```bash
scripts/bootstrap_android.sh          # JDK, Android SDK, NDK, Gradle
scripts/bootstrap_android.sh --full   # + Ghidra, jadx, apktool, Il2CppDumper
```

Everything lands under `$PAGENT_TOOLS` (default `~/.portagent-tools`).

## What each tool is for

| Tool | Stage | Purpose |
|---|---|---|
| `readelf` / `objdump` / `file` | Analyzer | augment pure-Python PE/ELF parsing |
| Ghidra (headless) | Decompiler | native x86 → pseudo-C |
| dnSpy / ILSpy | Decompiler | .NET assemblies → C# |
| jadx | Decompiler | DEX/APK → Java |
| Il2CppDumper | Decompiler | IL2CPP metadata → types/methods |
| Android SDK + NDK r26+ | Builder | arm64-v8a native build, APK packaging |
| Gradle | Builder | `assembleDebug` / `assembleRelease` |
| CMake / Ninja | Builder | native module build |
| DXVK / VKD3D | Translator | D3D9/11/12 → Vulkan at runtime |
| Box64 | Translator | x86_64 → ARM64 dynamic binary translation |
| Wine | Translator | Win32 runtime for the DBT/Winlator path |
| apktool | Builder | repack existing APKs |

## Environment variables

```bash
export ANDROID_HOME="$HOME/.portagent-tools/android-sdk"
export ANDROID_NDK_HOME="$ANDROID_HOME/ndk/26.1.10909125"
export PATH="$PATH:$ANDROID_HOME/cmdline-tools/latest/bin:$ANDROID_HOME/platform-tools"
```

## Test/CI requirements

The unit tests build real PE/ELF fixtures. Install the cross compilers with:

```bash
sudo apt-get install -y mingw-w64 gcc-aarch64-linux-gnu
```

Tests skip cleanly if they are missing. The Android SDK/NDK is **not** required
for tests — the Builder falls back to host compilation and reports `partial`.

## Notes on this environment

- No `/dev/kvm`, so the Android emulator cannot be accelerated; on-device
  performance verification (FPS/memory/temperature) is out of scope here.
- APK signing uses the Android debug keystore generated by Gradle; for release
  builds supply your own keystore and `assembleRelease`.
