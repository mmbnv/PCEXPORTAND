# PortAgent — всё в одной папке

Это самодостаточная сборка. Внутри уже лежит **и код, и все инструменты**, поэтому
не нужно ничего скачивать или настраивать вручную.

## Что внутри

```
portagent-bundle/
├── portagent/            код агента (Python, только стандартная библиотека)
├── run.py                меню запуска
├── tools/                все внешние инструменты
│   ├── android-sdk/      aapt2, d8, zipalign, apksigner, android.jar, NDK (clang)
│   ├── jadx/             декомпилятор dex -> java
│   ├── il2cppdumper/     разбор Unity IL2CPP
│   └── runtime/          Wine + Box64 + DXVK + Turnip (~475 МБ)
├── install.sh            подготовка (Linux/macOS)
├── START.sh              запуск   (Linux/macOS)
├── install.bat           подготовка (Windows)
├── START.bat             запуск   (Windows)
└── env.sh / env.bat      создаётся установщиком
```

## Как запустить

### Linux / macOS
```bash
cd portagent-bundle
./install.sh      # один раз: проверит инструменты и создаст env.sh
./START.sh        # меню
./START.sh --gui  # окно с кнопками (если есть Tkinter)
```

### Windows
```bat
cd portagent-bundle
install.bat
START.bat
```

## Что делает программа

1. Выбираете папку с установленной игрой.
2. Нажимаете «Build APK».
3. Программа анализирует игру (движок, архитектура, графический API, DRM),
   выбирает стратегию и собирает **устанавливаемый APK**.
4. Готовый файл появляется в рабочей папке (`portagent_run/`).

Для игр без исходников используется путь `wine_dxvk`: внутри APK лежат Box64,
Wine и DXVK, поэтому x86/x64-игра запускается на ARM64-телефоне.

## Честно о том, что работает

- Сборка APK, анализ, упаковка runtime — **работают** и проверены.
- Запуск на настоящем телефоне **не проверялся** (в среде сборки нет устройства).
  Поэтому никаких обещаний про FPS и точность кадров нет.
- Портируемость зависит от игры: античит и DRM на уровне ядра делают порт
  невозможным, и программа честно об этом сообщает.

## Если чего-то не хватает

`install.sh` показывает список: `OK` — есть, `MISS` — нет. Если `runtime`
отсутствует, его можно получить так (нужен интернет):
```bash
export PAGENT_TOOLS_HOME="$PWD/tools"
python -m portagent fetch-runtimes
```
